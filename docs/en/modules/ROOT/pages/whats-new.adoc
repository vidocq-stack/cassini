= What's new
:description: Everything that changed in this component since the {release-version} release.

[.lead]
New in the `{project-version}` development line — everything listed here landed **after the {release-version} release** and is not part of it. Every entry links to the section that documents it, and those sections carry the [.tag-new]#NEW# badge. Each brick of the suite keeps its own page of this kind; xref:home::whats-new.adoc[the ecosystem index] gathers them. When the next release train ships, this page is frozen with it and restarts empty on the dev line.

* xref:usage.adoc#unmapped-exceptions[An unmapped exception answers a bare `500`] [.tag-new]#NEW# — an exception or an error that no `ExceptionMapper` handles answers `500` with an empty body; its message, which may carry SQL text or request values, stays in the `ERROR` log with the stack trace instead of going to the client (CASSINI-046).
* xref:usage.adoc#locator-exceptions[A sub-resource locator's exception reaches the mappers] [.tag-new]#NEW# — an exception that a sub-resource locator throws goes through the application's `ExceptionMapper`s, as one from a resource method does; it skipped them and answered `500` unless it was a `WebApplicationException` (CASSINI-047).
* xref:reference.adoc#free-port[`SeBootstrap` binds a free port itself] [.tag-new]#NEW# — with `FREE_PORT` or no port, the server binds a free port of `127.0.0.1` and the instance's configuration reports it; the port was picked first and bound once the application was built, so another process could take it in between (CASSINI-049).
