= Getting started
:description: First JAX-RS resource served by Cassini on top of Chappe.

== Prerequisites

* **Java 25**, **Maven 4.0.0-rc-5** — `.sdkmanrc` at the repo root.
* Familiarity with Jakarta REST 4.0 basics (`@Path`, `@GET`, `@POST`, `Response`).

== Maven coordinates

[source,xml]
----
<dependencies>
    <dependency>

== Hello world

A standard JAX-RS resource:

[source,java]
----
package io.example;

import jakarta.ws.rs.GET;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.PathParam;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.MediaType;

@Path("/hello")
public class HelloResource {

    @GET
    @Produces(MediaType.TEXT_PLAIN)
    public String hello() {
        return "Hello, Cassini!";
    }

    @GET
    @Path("/{name}")
    @Produces(MediaType.APPLICATION_JSON)
    public Greeting greet(@PathParam("name") String name) {
        return new Greeting(name, "Hello, " + name);
    }

    public record Greeting(String name, String message) {}
}
----

Bootstrap:

[source,java]
----
import io.vidocq.cassini.chappe.CassiniStack;
import jakarta.ws.rs.core.Application;
import java.util.Set;

public class Main extends Application {
    @Override public Set<Class<?>> getClasses() {
        return Set.of(HelloResource.class);
    }

    public static void main(String[] args) throws Exception {
        try (var server = CassiniStack.builder()
                .application(new Main())
                .port(8080)
                .build()) {
            server.start();
            Thread.currentThread().join();
        }
    }
}
----

== Build and run

[source,bash]
----
sdk env
./mvnw -ntp install -DskipTests
mvn -pl cassini-examples -am exec:exec
----

[NOTE]
====
To wire CDI: add `cassini-cdi-vauban` to the classpath and mark resources `@ApplicationScoped`. Vauban resolves injection at compile time.
====

[TIP]
====
To run the official Jakarta REST 4.0 TCK: `./run-official-tck-restful-4.0.sh` at the `cassini` repo root. The `cassini-tck` module is intentionally out-of-reactor (ShrinkWrap constraint, see xref:reference.adoc[Reference]).
====
