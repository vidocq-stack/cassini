== Jakarta REST 4.0 annotations

All standard annotations are preserved. No expected change on user code if it is strictly spec-compliant — except JSON binding:

* RESTEasy/Jersey often delegate to Yasson or Jackson — Cassini delegates to xref:champollion::index.adoc[Champollion]. Serialization is static: add `champollion-codegen-apt` to the build for new types.
