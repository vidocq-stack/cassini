NOTE: `cassini-tck` is not published and is **out-of-reactor** (standalone `modelVersion 4.0.0` POM).

== Jakarta REST 4.0 compatibility

Supported annotations:

* `@Path`, `@GET`, `@POST`, `@PUT`, `@DELETE`, `@PATCH`, `@HEAD`, `@OPTIONS`
* `@Produces`, `@Consumes`
* `@PathParam`, `@QueryParam`, `@HeaderParam`, `@CookieParam`, `@FormParam`, `@MatrixParam`, `@BeanParam`
* `@Provider`, `@Priority`
* `@DefaultValue`, `@Encoded`

[TODO]: `@Suspended` + `AsyncResponse` to validate on the Chappe transport.

== Jakarta REST 4.0 TCK

[source,bash]
----
cd cassini
./run-official-tck-restful-4.0.sh             # smoke
./run-official-tck-restful-4.0.sh -Dtest=...  # targeted
----

`cassini-tck` is intentionally outside the parent `<subprojects>`. Reason: ShrinkWrap Maven Resolver 3.3 (transitive of the official TCK) cannot parse `Model 4.1.0` POMs. See `vidocq/CLAUDE.md` at the workspace root for full context.
