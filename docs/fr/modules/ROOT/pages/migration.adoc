== Annotations Jakarta REST 4.0

Toutes les annotations standards sont préservées. Pas de changement attendu sur le code utilisateur si le code source est strictement spec — sauf binding JSON :

* RESTEasy/Jersey délèguent souvent à Yasson ou Jackson — Cassini délègue à xref:champollion::index.adoc[Champollion]. La sérialisation est statique : ajouter `champollion-codegen-apt` au build pour les types nouveaux.
