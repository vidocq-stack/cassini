= Référence
:description: Artefacts Maven, modules JPMS, annotations supportées, configuration.

[.lead]
Référence factuelle : artefacts Maven publiés, modules JPMS exportés, annotations Jakarta REST 4.0 supportées, propriétés de configuration.

== Artefacts Maven

[cols="2,3"]
|===
| Artefact | Rôle

| `io.vidocq.cassini:cassini-api:0.1.0-SNAPSHOT`
| SPI publique (`CassiniHttpExchange`, `CassiniHttpAdapter`, `CassiniStack`, `BeanProvider`, `ResourceFactory`).

| `io.vidocq.cassini:cassini-core:0.1.0-SNAPSHOT`
| Moteur JAX-RS (Invoker, ResourceScanner, MessageBodyRegistry, filtres, providers, SSE, multipart).

| `io.vidocq.cassini:cassini-cdi-vauban:0.1.0-SNAPSHOT`
| Adapter `BeanProvider` qui résout les ressources via xref:vauban::index.adoc[Vauban] (BCE `CassiniScopeExtension` incluse).

| `io.vidocq.cassini:cassini-chappe:0.1.0-SNAPSHOT`
| Transport de référence — branche Cassini sur xref:chappe::index.adoc[Chappe] (HTTP/1.1, H2, virtual threads). Utilisé pour le TCK.

| `io.vidocq.cassini:cassini-jdk-http:0.1.0-SNAPSHOT`
| Transport JDK pur — `com.sun.net.httpserver.HttpServer`, zéro dépendance externe.

| `io.vidocq.cassini:cassini-examples-*`
| Exemples : `cassini-examples-chappe` (SE-Bootstrap standard), `cassini-examples-jdkhttp` (CassiniStack direct), `cassini-examples-vauban` (CDI + SE-Bootstrap).
|===

NOTE: `cassini-tck` n'est pas publié et est **hors-reactor** (POM `modelVersion 4.0.0` standalone). Voir xref:tck.adoc#runner-hors-reactor[TCK — runner hors-reactor].

== Modules JPMS

[cols="2,3"]
|===
| Module | Exports / Provides

| `io.vidocq.cassini.api`
a|
[source]
----
exports io.vidocq.cassini.spi.http;
exports io.vidocq.cassini.spi.resource;
exports io.vidocq.cassini.spi.bean;
uses io.vidocq.cassini.spi.http.CassiniStack.BuilderFactory;
uses io.vidocq.cassini.spi.bean.BeanProvider.Factory;
----

| `io.vidocq.cassini.core`
a|
Aucun export public. `internal.*` est ouvert uniquement aux modules
`cassini.tck`, `cassini.cdi`, `cassini.chappe`, `cassini.jdkhttp`,
`runtime.ext.rest.cassini`, `cassini.examples.vauban`.
[source]
----
provides io.vidocq.cassini.spi.http.CassiniStack.BuilderFactory
    with io.vidocq.cassini.internal.CassiniStackBuilderFactory;
----

| `io.vidocq.cassini.chappe`
a|
[source]
----
exports io.vidocq.cassini.chappe;
provides jakarta.ws.rs.ext.RuntimeDelegate
    with io.vidocq.cassini.chappe.ChappeRuntimeDelegate;
----

| `io.vidocq.cassini.jdkhttp`
a|
[source]
----
exports io.vidocq.cassini.jdkhttp;
provides jakarta.ws.rs.ext.RuntimeDelegate
    with io.vidocq.cassini.jdkhttp.JdkHttpRuntimeDelegate;
----

| `io.vidocq.cassini.cdi`
a|
[source]
----
exports io.vidocq.cassini.cdi;
provides io.vidocq.cassini.spi.resource.ResourceFactory
    with io.vidocq.cassini.cdi.CdiResourceFactory;
----
|===

NOTE: `cassini-core` n'expose **pas** son `CassiniRuntimeDelegate` via `ServiceLoader` — c'est volontaire pour éviter une collision avec le `RuntimeDelegate` du transport actif (`cassini-chappe` ou `cassini-jdk-http`).

== Annotations supportées

`@Path`, `@GET`, `@POST`, `@PUT`, `@DELETE`, `@PATCH`, `@HEAD`, `@OPTIONS`, `@HttpMethod`, `@ApplicationPath`,
`@Produces`, `@Consumes`,
`@PathParam`, `@QueryParam`, `@HeaderParam`, `@CookieParam`, `@FormParam`, `@MatrixParam`, `@BeanParam`,
`@DefaultValue`, `@Encoded`,
`@Provider`, `@Priority`, `@NameBinding`, `@PreMatching`,
`@Context`,

== Configuration

Cassini se configure via `SeBootstrap.Configuration` (standard) ou via le builder `CassiniStack.builder()` (avancé) :

[cols="2,1,3"]
|===
| Propriété | Défaut | Description
| `host` | `0.0.0.0` | Interface d'écoute du transport.
| `port` | `0` (auto) | Port HTTP. `0` = aléatoire libre.
| `rootPath` | `/` | Préfixe de montage de l'`Application`.
| `protocol` | `HTTP` | `HTTP` ou `HTTPS` (selon support transport).
|===

Quand Cassini est piloté par xref:vidocq::index.adoc[Vidocq Runtime] (extension `vidocq-rest-cassini`), deux propriétés MicroProfile Config supplémentaires :

[cols="2,1,3"]
|===
| Propriété | Défaut | Description
| `vidocq.rest.context-path` | `/` | Préfixe de montage JAX-RS dans le serveur Vidocq.
| `vidocq.rest.listener` | `default` | Listener Chappe cible.
|===
