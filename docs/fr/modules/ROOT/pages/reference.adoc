NOTE: `cassini-tck` n'est pas publié et est **hors-reactor** (POM `modelVersion 4.0.0` standalone).

== Compatibilité Jakarta REST 4.0

Les annotations supportées :

* `@Path`, `@GET`, `@POST`, `@PUT`, `@DELETE`, `@PATCH`, `@HEAD`, `@OPTIONS`
* `@Produces`, `@Consumes`
* `@PathParam`, `@QueryParam`, `@HeaderParam`, `@CookieParam`, `@FormParam`, `@MatrixParam`, `@BeanParam`
* `@Provider`, `@Priority`
* `@DefaultValue`, `@Encoded`

[TODO] : `@Suspended` + `AsyncResponse` à valider sur le transport Chappe.

== TCK Jakarta REST 4.0

[source,bash]
----
cd cassini
./run-official-tck-restful-4.0.sh             # smoke
./run-official-tck-restful-4.0.sh -Dtest=...  # ciblé
----

`cassini-tck` est délibérément hors `<subprojects>` du parent POM. Raison : ShrinkWrap Maven Resolver 3.3 (transitive du TCK officiel) ne sait pas parser les POMs `Model 4.1.0`. Voir `vidocq/CLAUDE.md` à la racine du workspace pour le contexte complet.
