= Cassini
:description: Implémentation Jakarta RESTful Web Services 4.0 (Core Profile / SE-Bootstrap), transport-agnostique, JPMS natif, Java 25.

[.text-center]
image::cassini-logo.png[Cassini,300,role=module-logo]


[.lead]
Cassini est l'implémentation Jakarta REST 4.0 de l'écosystème Vidocq. Elle s'appuie sur xref:chappe::index.adoc[Chappe] pour le transport HTTP, sur xref:vauban::index.adoc[Vauban] pour la résolution CDI, et sur xref:champollion::index.adoc[Champollion] pour la sérialisation JSON. Elle vise la conformité TCK 100 % sur la cible Core Profile / SE-Bootstrap, sans réflexion ad hoc et sans dépendance externe injustifiée.

== Origine du nom

**Giovanni Domenico Cassini**, francisé en **Jean-Dominique Cassini** (1625–1712), astronome italo-français, premier directeur de l'Observatoire de Paris (1671). Il fonda la dynastie qui dressa la première carte complète de France par triangulation géodésique — chaque point du royaume rattaché à un réseau hiérarchique de triangles, puis à des chemins, puis à des lieux nommés.

Lien : https://fr.wikipedia.org/wiki/Giovanni_Domenico_Cassini[Cassini sur Wikipédia].

[cols="1,3"]
|===
| Cassini, l'astronome | Cassini, le runtime
| Triangulation géodésique | URI templates `@Path("/a/\{b\}/c")`
| Mesh hiérarchique royaume → province → ville | Root resource → sub-resource locator → method
| Méridien de référence | `UriInfo.getBaseUri()`
| Point unique par 3 angles | Best-match : méthode unique par (path, verb, media-type)
|===

L'arborescence des ressources REST est une carte. Cassini est le runtime qui la dresse et y route chaque requête — sur les lignes de signalisation tracées par le télégraphe optique de xref:chappe::index.adoc[Chappe].

Cassini partage Chappe avec xref:foy::index.adoc[Foy] (Servlet 6.1) : un même process peut exposer une application JAX-RS et un déploiement Servlet sur le même listener.
